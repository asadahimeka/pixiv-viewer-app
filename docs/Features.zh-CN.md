# 功能特性

简体中文 | [English](./Features.md)

> 返回 [README](./README.zh-CN.md)

又一个 Pixiv 阅览工具，提供 Pixiv 插画、动图、漫画和小说等作品的在线浏览，支持多平台客户端（Android / iOS / Windows / macOS / Linux）与多种浏览布局。支持自定义 API 实例与图床，支持 RefreshToken / OAuth / Cookie 方式登录。

## ✨ 功能特性

| 功能 | 说明 |
| --- | --- |
| 多类型内容浏览 | 插画、漫画、小说、珍藏册等 |
| 排行榜 | 每日热门作品排行 |

### 🈶 漫画翻译

| 功能 | 说明 |
| --- | --- |
| 一键翻译 | 内置翻译引擎 |
| 本地推理 | 通过 ONNX Runtime Web（WebGPU/WASM）在 Web Worker 中完成文本检测 / OCR / 图像修复 |
| 排版引擎 | 横排 / 竖排文字，自动匹配气泡与阅读顺序 |
| 多模型提供商 | SiliconCloud 等 OpenAI 兼容 LLM，或自建服务端翻译引擎 |
| 原图 / 译文切换 | 一键对比翻译结果 |

### ⚙️ 设置

#### 登录方式

| 功能 | 说明 |
| --- | --- |
| RefreshToken 登录 | 使用 Pixiv RefreshToken 直接登录 |
| OAuth 登录 | 通过 Pixiv OAuth 授权登录 |
| Cookie 登录 | Cookie 方式登录（不推荐） |

#### 内容控制

| 功能 | 说明 |
| --- | --- |
| R18 开关 | 控制是否显示成人内容 |
| AI 作品开关 | 控制是否显示 AI 生成的作品 |
| 本地黑名单 | 屏蔽标签 / 用户，标签化 UI 管理，可单独移除 |

#### 浏览体验

| 功能 | 说明 |
| --- | --- |
| 多语言支持 | 简体 / 繁体中文、英文、日文、韩文、俄文等（14 种语言） |
| 深色模式 | 护眼夜间模式 |
| 主题色自定义 | 自定义应用主题颜色 |
| 图片信息流布局 | 瀑布流、网格、两端对齐、虚拟列表、虚拟轮播等 |
| 图片画质选择 | Medium / Large / Large(WebP) 等 |
| 页面过渡动画 | 多种页面切换动画效果（View Transitions API） |

#### 网络与数据

| 功能 | 说明 |
| --- | --- |
| 多图床选择 | 切换多个图片反代服务 |
| 多 API 实例选择 | 切换多个后端 API 实例 |
| AppAPI 代理模式 | 直连 Pixiv App API（需自建代理） |
| pximg 图片直连 | 直连 Pixiv 原图服务器（Web 版需配合 Tampermonkey 辅助脚本） |
| IndexedDB 缓存 | 本地缓存提升加载速度 |
| 历史记录 | 查看作品浏览历史 |
| 清除缓存 | 一键清除应用缓存 |

#### 下载功能

| 功能 | 说明 |
| --- | --- |
| 列表长按下载 | 长按列表图片快速下载 |
| 列表长按屏蔽 | 长按快速屏蔽用户 |
| 文件名格式自定义 | 自定义下载文件名模板 |
| 动图多格式导出 | ZIP / GIF / WebM / APNG / MP4 / AVIF |
| Tampermonkey 支持 | Web 版可通过油猴脚本 + HTTP Helper 下载 |

#### 备份与同步

| 功能 | 说明 |
| --- | --- |
| 设置备份 | 备份 / 还原应用设置 |
| 浏览记录备份 | 备份 / 还原浏览历史 |
| 云端同步 | PBKDF2 + AES 加密，冲突检测与智能合并 |
| 导出 RefreshToken | 导出 Token 供其他应用使用 |

#### 📱 客户端支持

| 平台 | 分发方式 |
| --- | --- |
| Web / PWA | 静态托管（如 Cloudflare Pages） |
| Android | Universal APK（Capacitor） |
| iOS | 未签名 IPA，需自行签名单侧载（Capacitor） |
| Windows | EXE / MSI 安装包（Tauri） |
| macOS | DMG / APP，支持 Apple Silicon 与 Intel（Tauri） |
| Linux | deb / rpm / AppImage / Arch 包（Tauri） |
